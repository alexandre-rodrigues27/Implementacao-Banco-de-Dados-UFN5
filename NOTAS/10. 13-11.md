📊 Teste de Performance e Índices no SQL Server
📌 Objetivo

Este projeto tem como objetivo estudar o desempenho de consultas SQL no SQL Server, utilizando uma tabela com grande volume de dados e comparando consultas com e sem índices.

🗄️ 1. Criação da Tabela
sql
CREATE TABLE Funcionario (
    Id INT PRIMARY KEY,
    Nome VARCHAR(100),
    Cargo VARCHAR(50),
    Salario DECIMAL(10,2),
    DataAdmissao DATE
);

📝 2. Inserção de Dados

Primeiramente, são inseridos cinco funcionários manualmente. Em seguida, utilizamos um loop WHILE para gerar mais 300.000 registros automaticamente.

sql
INSERT INTO Funcionario
VALUES 
    (1, 'Jão', 'Adm', 3500, GETDATE()),
    (2, 'Alex', 'Estagiário', 450, GETDATE()),
    (3, 'Maria', 'TI', 2100, GETDATE()),
    (4, 'Rodrigo', 'Suporte', 1400, GETDATE()),
    (5, 'Carla', 'Limpeza', 1100, GETDATE());


DECLARE @contador INT = 1;
DECLARE @Id INT;

SELECT @Id = ISNULL(MAX(Id), 0) FROM Funcionario;

WHILE @contador <= 300000
BEGIN
    SET @Id = @Id + 1;

    INSERT INTO Funcionario
    VALUES (
        @Id,
        'Funcionário' + CAST(@Id AS VARCHAR(10)),

        CASE @contador % 5
            WHEN 0 THEN 'Gerente'
            WHEN 1 THEN 'Desenvolvedor'
            WHEN 2 THEN 'Analista'
            WHEN 3 THEN 'Suporte'
            ELSE 'Financeiro'
        END,

        FLOOR(10000 + RAND()) + 1600,

        DATEADD(DAY, @contador % 3650, '20150101')
    );

    SET @contador = @contador + 1;
END
GO
